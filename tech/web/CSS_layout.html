float

This basically aligns the element with a side (right or left) of its container, and makes text of the container flow around it. The wikipedia infobox uses it for example.

Usage:

.elt {
    float: right;
}

@media rules

This is like a way to enable a bunch of selectors if some condition is true, such as the user prefers dark mode or their screen is over this resolution etc
