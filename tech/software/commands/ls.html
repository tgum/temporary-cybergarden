ls [flags] [directory]

list files in a directory (defaults to current)

  • -a: include files that start with a .
  • -1: show only 1 file per line
  • -l: show more info about the files (modify time, perms, size)
  • -F: add a symbol at the end of filenames to show properties (/ = directories, * = executable. idk the others)
