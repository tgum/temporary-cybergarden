how it werks

it reads a text program starting at address 1000, converts it to executable instructions and jumps there

syntax

  • uppercase letter = opcode (view table)
  • optional minus (technically van be anywhere in the number but shh) and sequence of digits = number
  • anything else = ignored (except to mark the end of a number)

example program:

  // disable debug
  Psh 0 Psh -102 Str
  Psh &string (1023)
loop:
  Dup
  Lds
  Dup
  Psh 2
 Qrcj
  Hlt // halt if encounter zero
  Psh -101 // print char
  Str
  Psh 1
  Add
  Psh &loop (1007)
  Jmp
string:

@outcounter: 0
@incounter:  0
@number:     0
@numberstate:0
Psh init(100)
popV // change this instruction to a jmp in the compiled version so it runs the assembler instead of itself lol

  @print program
Psh usercode (1000)
@loop
// print number and comma
Dup Lds Psh -100 Str
Psh 44 Psh -101 Str
Psh 1 Add
// jump to end if done printing
Dup Psh outcounter(0) Lds
sUb iBz Not Psh 4 rcj Q
// restart
Psh loop (-25) rjp E
// print newline and program length
Psh 10 Psh -101 Str Psh 999 sUb Psh -100 Str Hlt

  @zero padding until address one hundred

  @init
// fix variables
Psh 1000 Dup Psh outcounter(0) Str Psh incounter(1) Str
Psh 0 Dup Psh number(2) Str Psh numberstate(3) Str

  @start
Psh incounter(1) Lds Dup Lds
// stop reading on null
Dup Not Psh jumpuser(262) Cjp
sWp
// increment by one
Psh 1 Add Psh incounter(1) Str

  @isminus
Dup
// skip rest of subroutine if its not a minus
Psh minus(45) sUb Psh isnumber(151) Cjp
Psh -1 Psh numberstate(3) Str
popV Psh start(118) Jmp

  @isnumber
Dup
Psh digitzero(48)
sUb
// if ascii is less than digitzero its not a digit
Dup iBz Psh notnumber(194) Cjp
// if its greater than digitzero+ten its not a digit
Dup Psh 10 sUb iBz Not Psh notnumber(194) Cjp
// if sarting a number, mark it as positive
Psh numberstate(3) Lds Psh 6 rcjQ
Psh 1 Psh numberstate(3) Str
// store the digit
Psh number(2) Lds
Psh 10 Mul
Add
Psh number(2) Str
// restart loop
popV Psh start(118) Jmp

  @notnumber
popV
// skip the rest if we didnt just finish a number
Psh numberstate(3) Lds Not Psh isletter(221) Cjp
// give correct sign to the number
Psh numberstate(3) Lds Psh number(2) Lds Mul
Psh writeprogram(248) cllF
// reset variables
Psh 0 Dup Psh number(2) Str Psh numberstate(3) Str

  @isletter
Psh capital_a(65) sUb
Dup iBz Psh notletter(244) Cjp
Dup Psh 26 sUb iBz Not Psh notletter(244) Cjp
Psh writeopcode(267) cllF
Psh start(118) Jmp

  @notletter
popV Psh start(118) Jmp

  @writeprogram
Psh outcounter(0) Lds Str
Psh outcounter(0) Lds Psh 1 Add Psh outcounter(0) Str
Ret

  @jumpuser
popV popV Psh usercode(1000) Jmp

  @writeopcode
Psh opcodetable(275) Add Lds
Psh writeprogram(248) cllF
Ret
